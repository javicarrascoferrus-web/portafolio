JAVI_OS — Juego 2D top-down para GitHub Pages

Abre juego/index.html en el navegador.
Controles: WASD/flechas para moverte, E/espacio para interactuar, ESC para cerrar.
En móvil utiliza los botones táctiles.

Sube todo el contenido de portafolio_javi_os_jugable a la raíz de tu repositorio portafolio.
No necesita instalación ni dependencias de JavaScript.
La fuente retro es opcional y se carga desde Google Fonts.
El progreso se guarda localmente en el navegador.
