Tienda Online

Proyecto original desarrollado con Python y Flask. Esta versión es una demostración interactiva adaptada para funcionar en GitHub Pages.

Sobre el proyecto

Esta demo reproduce las principales funcionalidades de una tienda online: catálogo de productos, búsqueda, filtros por categoría, carrito de compras y simulación de compra.

El proyecto original fue desarrollado utilizando Python y Flask, con gestión del carrito mediante sesiones.
